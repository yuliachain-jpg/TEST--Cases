 TEST CASES PORTFOLIO

В данном репозитории собраны тест-кейсы, созданные в рамках практики Manual QA.


**Цель:** Продемонстрировать навыки разработки, структурирования и документирования тест-кейсов, проверки функциональности и валидации пользовательского ввода.

### Test Cases 

| ID | Test Case Summary | Testing Type | Status / Notes |
|---|---|---|---|
| TC-001 | Успешная авторизация с корректными данными | Functional Testing | Позитивный сценарий |
| TC-002 | Добавление товара в корзину и сохранение после обновления страницы | Functional Testing | Проверка сохранения состояния |
| [TC-003](https://github.com/yuliachain-jpg/TEST--Cases/issues/3) | BVA Project: Проверка поля «Количество товара» | Boundary Value Analysis (BVA) | Проверка граничных значений |
| [TC-004](https://github.com/yuliachain-jpg/TEST--Cases/issues/4) | Авторизация пользователя с валидными данными | Functional Testing | Позитивный сценарий |
| [TC-005](https://github.com/yuliachain-jpg/TEST--Cases/issues/5) | Equivalence Partitioning: Проверка валидации поля «Возраст» | Equivalence Partitioning (EP) | Проверка классов эквивалентности |

### Skills Demonstrated

- Разработка тест-кейсов (Test Case Design)

- Функциональное тестирование (Functional Testing)

- Позитивное тестирование (Positive Testing)

- Анализ граничных значений (Boundary Value Analysis, BVA)

- Разбиение на классы эквивалентности (Equivalence Partitioning, EP)

- Документирование тестирования (Test Documentation)

- Тестирование валидации данных (Validation Testing)

- Ручное тестирование (Manual QA)
